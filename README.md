# lhds-3 · La Hermana de Shakespeare (borrador)

La misma página de [lhds-2](https://github.com/uiuaaxyz/lhds-2), pero con aspecto de **borrador / boceto**:
papel cuadriculado, letra a mano, bordes "dibujados", cajas vacías donde van las fotos y el logo,
y notas amarillas al margen con lo que falta por decidir.

Sirve para revisar la estructura y el contenido con el equipo antes de diseñar la versión final.

Para verlo, abre `index.html` en el navegador.

## Archivos
- `index.html`, `archivo.html`, `aviso-legal.html`: mismas secciones que la versión final
- `css/borrador.css`: estilos de lhds-2 en grises + la capa de boceto (al final del archivo)
- `js/script.js`: menú, filtros, pestañas y formulario (ejemplos de W3Schools)
- `docs/`: bases de convocatorias de ejemplo
